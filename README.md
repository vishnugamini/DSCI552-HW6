## Run
Use Python 3.12. Install dependencies with `pip install -r requirements.txt`.
Open `notebook/Gamini_Vishnu_HW6.ipynb`, restart the kernel, and run all cells.
On macOS, XGBoost may require `brew install libomp`.

Data: `data/aps_failure/`. Results: `data/results/`. Helpers: `src/`.
The full training set is used, including for SMOTE. Execution takes several minutes.
